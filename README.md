## 🚀 Key Projects & Architectural Showcases

### 🎬 SimplyCinema | Movie Booking & Theatre Management Platform
* 🔒 **Race Condition Solution:** Prevented seat double-booking during concurrent checkouts using **Redis TTL distributed locks** combined with **WebSockets (STOMP)** for low-latency live seat updates.
* 🛠️ **Production REST APIs:** Shipped **90+ REST APIs** across 4 roles (Customer, Admin, Owner, Staff), utilizing SOLID principles and global exception handling.
* ☁️ **Security & Deployment:** Secured endpoints via stateless **Spring Security (JWT + OAuth2 + RBAC)** and deployed on **AWS EC2** behind an Nginx reverse proxy with Razorpay payment integration.

### 🛒 SimplyBuy | Distributed E-Commerce Platform
* 🗺️ **Microservice Cluster:** Built an **8-microservice cluster** utilizing **Spring Cloud Gateway**, Eureka Service Discovery, and Spring Cloud Config for dynamic routing and load balancing.
* 🛡️ **Fault Tolerance:** Prevented cascading outages across services by implementing **Resilience4j Circuit Breakers**.
* ⚡ **Asynchronous Messaging:** Decoupled order and notification pipelines via **Apache Kafka**, removing blocking calls from the critical checkout path.
* 📊 **Observability & Deployment:** Orchestrated services using **Docker Compose** and integrated **Zipkin** for full-path distributed tracing.
